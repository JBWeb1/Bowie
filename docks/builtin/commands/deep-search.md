description: Research a question in depth on the web and write a sourced report
argument-hint: "QUESTION"
---
Do a deep search on: $ARGUMENTS

1. Break the question into the 3 to 6 things you need to find out.
2. Search the web for each, using different wordings, and open the most useful pages (official sources, the
   original study or announcement, and recent news) rather than relying on search snippets.
3. Check facts against at least two independent sources. Where sources disagree, say so and say which you trust
   more and why. Note the date of anything that changes over time (prices, versions, laws, scores).
4. Write the answer as a short report: the direct answer first, then the key findings with a source link after
   each, then what is still uncertain. Save it as research/<short-name>.md in the project and give me the
   summary here.

If you have no web search (for example on Bowers Local), say so plainly and answer only from what you know,
labelled as possibly out of date.
